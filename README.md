## 👥 Team Collaboration (Group 7)
[cite_start]This project was a collaborative effort by Group 7 for the **SEMM4533 System Design** course[cite: 1, 4, 18]. 

### **My Core Contributions (Lawrance Sim)**
As the lead for the **Communication & Logic Implementation**, I was responsible for:
* [cite_start]**Dual-Platform IoT Integration**: Engineered the real-time telemetry system using **Blynk** for visual data plotting and **Telegram Bot API** for urgent remote alerts[cite: 969, 1001, 1004].
* **Anti-False-Alarm Mechanism**: Developed the **Confirmation Logic** (`dangerCount` system). [cite_start]By implementing a 2-second temporal validation (20-cycle threshold), I successfully eliminated false triggers caused by water ripples or environmental noise[cite: 971, 995, 996].
* [cite_start]**Production Codebase**: Finalized and debugged the integrated source code to ensure seamless communication between sensors, local hardware alerts, and cloud servers[cite: 982, 1007].

* [cite_start]**Hardware & Embodiment**: Mechanical design of the IP65-rated housing and 3D modeling of the pole-mounting system[cite: 73, 672, 916].
