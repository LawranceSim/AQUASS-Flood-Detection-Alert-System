## 👥 Team Collaboration (Group 7)
This project was a collaborative effort by Group 7 for the **SEMM4533 System Design** course. 

### **My Core Contributions (Lawrance Sim)**
As the lead for the **Communication & Data Systems Lead**, I was responsible for:
* **Dual-Platform IoT Integration**: Engineered the real-time telemetry system using **Blynk** for visual data plotting and **Telegram Bot API** for urgent remote alerts.
* **Anti-False-Alarm Mechanism**: Developed the **Confirmation Logic** (`dangerCount` system). By implementing a 2-second temporal validation (20-cycle threshold), I successfully eliminated false triggers caused by water ripples or environmental noise.
* **Production Codebase**: Finalized and debugged the integrated source code to ensure seamless communication between sensors, local hardware alerts, and cloud servers.

### **Other Team Contributions**
* **Signal Processing**: Implementation of **Median** and **Moving Average Filters** to stabilize ultrasonic sensor readings.
* **Hardware & Embodiment**: Mechanical design of the IP65-rated housing and 3D modeling of the pole-mounting system.
* **System Design**: Drafting of the Product Design Specifications (PDS) and Flowcharts.
